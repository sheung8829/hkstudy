# 新增「小挑戰」遊戲模組計畫

本計畫將為應用程式新增一個互動式的遊戲化學習模組，包含「生字解釋配對」與「選擇題」兩種模式。

## 1. 元件架構 (Component Structure)

將在 `src/components/games` 目錄下建立以下新元件：

* **`ChallengeHub.tsx`**:

  * 遊戲模組的主容器。

  * 負責顯示「遊戲選單」，讓使用者選擇要玩的模式（配對或選擇題）。

  * 負責根據篩選的課文 (filtered words) 初始化遊戲數據。

  * 管理遊戲狀態（選單 -> 遊戲中 -> 結算）。

* **`MatchingGame.tsx`** (生字解釋配對):

  * **邏輯**: 從生字庫中隨機全部生詞。左側顯示生字卡，右側顯示解釋卡（順序打亂）。

  * **互動**: 使用者需依序點擊一組生字與解釋。配對成功則消除或標記成功；失敗則提示錯誤。

  * **目標**: 最快時間內完成所有配對。

* **`MultipleChoiceGame.tsx`** (選擇題):

  * **邏輯**: 隨機出題（全部 題）。題目顯示「生字」，選項提供 4 個「解釋」（1 正 3 誤）。

  * **互動**: 點擊選項作答。答對加分並播放發音；答錯顯示正確答案。

  * **目標**: 取得最高分。

## 2. 整合至主程式 (App Integration)

* **`App.tsx`**:

  * 新增 `showChallenge` 狀態。

  * 在主畫面 Header 區域（「開始温習」按鈕旁）新增「**小挑戰**」按鈕。

  * 當點擊按鈕時，隱藏主列表，顯示 `ChallengeHub` 元件。

  * 將 `filteredWords`（依課文篩選後的生字）傳遞給 `ChallengeHub`，確保遊戲內容符合使用者當前的篩選範圍。

## 3. 實作細節

### 3.1 配對遊戲 (Matching Game)

* 使用 Grid 佈局顯示卡片。

* 狀態管理：`selectedId` (當前選中的卡片), `matchedIds` (已配對成功的 ID 列表)。

* 點擊生字時自動播放發音。

### 3.2 選擇題 (Multiple Choice)

* 題目生成演算法：確保干擾選項來自其他生字，且不重複。

* 進度條顯示：目前第幾題 / 總題數。

* 結算畫面：顯示答對率和評語。

## 4. 執行步驟

1. 建立 `src/components/games` 資料夾。
2. 實作 `MatchingGame.tsx`。
3. 實作 `MultipleChoiceGame.tsx`。
4. 實作 `ChallengeHub.tsx` 整合上述兩者。
5. 更新 `App.tsx` 引入入口按鈕與路由邏輯。
6. 驗證遊戲流程與發音功能。
